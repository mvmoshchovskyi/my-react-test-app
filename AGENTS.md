# Project conventions

- All code, comments, UI copy, documentation and commit messages are written in
  **English**.
- Ukrainian is only used for chat communication with the user.
- Keep the stack as is: React 19 + TypeScript + Vite, React Router 8,
  styled-components 6.
- Verify every change with `npm run build` and `npm run lint`.
- Prefer small, focused changes; keep the existing folder structure and naming.
